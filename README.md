# Sanjay S. — Premium Cinematic Glass Portfolio

A multi-page React portfolio for Sanjay S., built around a cinematic full-3D hero, the original 299-frame Full HD scroll sequence, and a refined glassmorphism visual system.

## Pages
- `/` — cinematic homepage, scroll-controlled story sequence and selected projects
- `/about` — profile, experience timeline, technical skills and external profiles
- `/work` — project index
- `/work/xbow`, `/work/skoobie-pro`, `/work/wireduard`, `/work/rogot`, `/work/ares-x` — project detail pages
- `/contact` — contact page

## Resume-led content
The site uses the attached resume as its content source: Kerala Police Cyber Cell internship, CC Cyber Campus internship, Hack The Box practice, HackerOne research, independent tool development, education and listed technical skills. Project names include XBow, Skoobie / Skoobie Pro, Wireduard and ROGOT. Descriptions are kept conservative where the resume does not provide implementation details.

## Visual system
- Cinematic dark palette with emerald accents
- Frosted-glass panels, layered translucency, blur, subtle edge highlights and soft shadows
- Three.js / React Three Fiber 3D hero scenes
- Original 299 JPEG frames at 1920 × 1080, retained without recompression
- Responsive layout and animated route transitions

## Run locally (Windows PowerShell)
From the extracted project folder:

```powershell
npm.cmd install
npm.cmd run dev
```

Run a production build before deployment:

```powershell
npm.cmd run build
```
